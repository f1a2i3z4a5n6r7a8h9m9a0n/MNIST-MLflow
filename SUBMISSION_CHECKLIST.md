- [ ] Put the real GitHub URL, DagsHub repository URL and MLflow Tracking URI in your assignment Word document with the screenshots.
- [ ] Push code and small actual result artifacts to GitHub; exclude .env, tokens, .venv, .tracking and model binaries.
- [ ] Submit train.py as Python code on DC Connect. Include the supporting notebook and files if permitted by the portal.
